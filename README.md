#11111 DoorHan - Информационный сайт на PHP

## О проекте

Это простой информационный сайт на PHP для компании DoorHan. Сайт имеет публичную часть на английском языке и панель администратора на русском.

## Последние изменения

Веб-сайт был значительно обновлен и преобразован из статического набора страниц в динамическое, управляемое базой данных приложение. Ключевые улучшения включают:

-   **Динамический контент:** Весь контент, включая страницы, продукты и новости, теперь управляется через базу данных.
-   **Безопасная контактная форма:** Контактная форма защищена с помощью CSRF-токенов и надежной проверки вводимых данных на стороне сервера.
-   **Пагинация:** На страницах "Новости" и "Продукты" добавлена пагинация для улучшения навигации.
-   **Динамическая навигация и футер:** Главное навигационное меню и содержимое футера теперь генерируются динамически из базы данных, что упрощает их обновление.
-   **Адаптивный дизайн:** Сайт теперь полностью адаптивен и включает мобильное "гамбургер-меню" для небольших экранов.
-   **Вертикальное выпадающее меню:** Пункт навигации "Продукты" теперь имеет вертикальное выпадающее меню для отображения подкатегорий.

## Требования

-   PHP 7.4
-   MySQL 5.7
-   Расширение `php-mysql`

## Руководство по развертыванию

### Настройка локального сервера для разработки

Это руководство предназначено для настройки проекта на локальной машине под управлением ОС на базе Debian (например, Ubuntu).

**Требования:**
- PHP 7.4
- MySQL 5.7
- Расширение `php-mysql`

**Шаги:**

1.  **Установите зависимости:**
    ```bash
    sudo apt-get update
    sudo apt-get install -y php php-mysql mysql-server
    ```

2.  **Запустите и настройте MySQL:**
    ```bash
    sudo service mysql start
    ```

3.  **Создайте и настройте базу данных:**
    Проект по умолчанию использует имя базы данных `doorhan` и пользователя `root` без пароля.

    ```bash
    # Создайте базу данных
    sudo mysql -u root -e "CREATE DATABASE doorhan;"

    # Настройте права доступа для пользователя root
    sudo mysql -u root -e "GRANT ALL PRIVILEGES ON doorhan.* TO 'root'@'localhost';"
    sudo mysql -u root -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '';"

    # Импортируйте схему и начальные данные
    sudo mysql -u root doorhan < schema.sql
    sudo mysql -u root doorhan < seed.sql
    ```

4.  **Настройте конфигурацию приложения:**
    Скопируйте файл конфигурации:
    ```bash
    cp config/config.php.example config/config.php
    ```
    При необходимости измените параметры доступа к базе данных в `config/config.php`.

5.  **Запустите встроенный веб-сервер PHP:**
    Корнем веб-сервера должна быть директория `public/`.
    ```bash
    php -S 0.0.0.0:8080 -t public
    ```
    Сайт будет доступен по адресу `http://localhost:8080`.

### Развертывание на внешнем веб-сервере

Это руководство описывает общие шаги для развертывания проекта на производственном сервере.

**Требования:**
- Веб-сервер (например, Apache или Nginx)
- PHP 7.4
- MySQL 5.7
- Расширение `php-mysql`

**Шаги:**

1.  **Загрузите файлы проекта на сервер:**
    Скопируйте все файлы проекта на ваш сервер, например, в директорию `/var/www/doorhan`.

2.  **Настройте веб-сервер:**
    -   Укажите в качестве корневой директории (DocumentRoot) папку `public/`. Это важно для безопасности, так как предотвращает прямой доступ к файлам приложения.
    -   Убедитесь, что веб-сервер имеет права на чтение файлов проекта.

    *Пример конфигурации для Apache:*
    ```apache
    <VirtualHost *:80>
        ServerName yourdomain.com
        DocumentRoot /var/www/doorhan/public

        <Directory /var/www/doorhan/public>
            AllowOverride All
            Require all granted
        </Directory>
    </VirtualHost>
    ```

    *Пример конфигурации для Nginx:*
    ```nginx
    server {
        listen 80;
        server_name yourdomain.com;
        root /var/www/doorhan/public;

        index index.php;

        location / {
            try_files $uri $uri/ /index.php?$query_string;
        }

        location ~ \.php$ {
            include snippets/fastcgi-php.conf;
            fastcgi_pass unix:/var/run/php/php7.4-fpm.sock;
        }
    }
    ```

3.  **Создайте и настройте базу данных:**
    -   Создайте базу данных и пользователя в MySQL.
    -   Предоставьте пользователю необходимые права на базу данных.
    -   Импортируйте `schema.sql` и `seed.sql` в вашу базу данных.

    *Пример команд:*
    ```bash
    # Замените 'your_user' и 'your_password' на свои значения
    mysql -u root -p -e "CREATE DATABASE doorhan;"
    mysql -u root -p -e "CREATE USER 'your_user'@'localhost' IDENTIFIED BY 'your_password';"
    mysql -u root -p -e "GRANT ALL PRIVILEGES ON doorhan.* TO 'your_user'@'localhost';"
    mysql -u your_user -p doorhan < schema.sql
    mysql -u your_user -p doorhan < seed.sql
    ```

4.  **Настройте конфигурацию приложения:**
    -   Скопируйте `config/config.php.example` в `config/config.php`.
    -   Откройте `config/config.php` и измените следующие параметры:
        -   `DB_HOST`, `DB_USER`, `DB_PASS`, `DB_NAME`: укажите данные для подключения к вашей базе данных.
        -   `SITE_URL`: укажите URL вашего сайта (например, `http://yourdomain.com`).
        -   `DEBUG`: установите значение `false` для производственной среды.

5.  **Настройте права доступа:**
    Если вы планируете использовать логирование ошибок в файлы, убедитесь, что директория `logs/` существует и доступна для записи веб-серверу.

6.  **Перезапустите веб-сервер:**
    ```bash
    # Для Apache
    sudo systemctl restart apache2

    # Для Nginx
    sudo systemctl restart nginx
    ```
    После выполнения этих шагов ваш сайт должен быть доступен по указанному домену.

## Переменные окружения

В данном проекте конфигурация хранится в файле `config/config.php`. Основные параметры:
- `DB_HOST`: хост базы данных
- `DB_USER`: имя пользователя базы данных
- `DB_PASS`: пароль пользователя базы данных
- `DB_NAME`: имя базы данных
- `SITE_URL`: URL сайта
- `ADMIN_EMAIL`: Email администратора для уведомлений
